# Security

Use this receiver only on a trusted local network. Its discovery and media
listeners are intended for nearby devices; do not forward their ports to the
Internet. It does not implement an Internet-facing relay or a remote update
execution mechanism. Pairing identity is stored in the current user's profile.

Download only from the repository's Releases page. Verify SHA-256 values and,
when available, Authenticode publisher signatures. A preview build without an
identity-validated certificate is identified as unsigned. Never disable
Windows security protections as an installation step.

For a vulnerability, use the repository's private vulnerability reporting
feature when available. Avoid posting pairing keys, local device captures or
credentials in public issues. Dependency versions, SBOMs and source locks are
included to support coordinated updates and review.
