# Fucairserver

接收 Mac、iPhone 和 iPad 的 AirPlay 画面及声音。Mac 可以选择镜像或扩展桌面。

1. 在本项目 GitHub Releases 下载 `Fucairserver-版本-windows-x64-setup.exe`。
2. 双击安装，确认 Windows 的管理员授权。默认安装到 Program Files。
3. 保留“允许专用网络和域网络中的局域网设备连接”，完成后打开 Fucairserver。
4. 让发送设备与电脑连接同一局域网，在屏幕镜像列表选择 Fucairserver。

支持目标是 Windows 10 22H2（19045）x64 和 Windows 11 x64。
32 位 Windows 和 ARM64 尚不在本发行版的验收范围内。
Windows 10 的系统更新支持取决于微软的生命周期及设备的 ESU 状态。

“设置”中可选择界面语言（跟随系统、简体中文或 English）和外观（跟随系统、
浅色或深色），并保存设备名称、接收分辨率和录制目录。

“声音”中可设置是否在这台电脑上播放收到的声音，以及音量和静音，立即生效。
macOS 的屏幕镜像要求接收端支持音频，接收器因此始终声明音频能力；
否则 Mac 会在约一分钟后判定激活超时并断开。Mac 投屏时会把声音输出切到
这台电脑，想继续用 Mac 那边（例如 AirPods）听，在 Mac 菜单栏“声音”里改选输出，
投屏不会因此中断。

`mac/keep-mac-audio` 可在 Mac 上自动做这一步：在 Mac 上执行
`./install.sh [接收器名称]` 安装后台小程序，投屏开始时 macOS 抢走的声音输出会被
切回原来的设备；之后在“声音”里主动选择接收器则保持不变。
`./install.sh --uninstall` 移除，日志在 `~/.fucairserver/keep-mac-audio.log`。

“键鼠跨屏”让 Mac 的键盘和鼠标直接操作这台电脑，类似 Mac 与 iPad 的通用控制：
把 Mac 的指针推过屏幕边缘就到电脑上，推回来就回到 Mac。Mac 端是菜单栏小程序
FucairEdge，在 Mac 上执行 `mac/fucair-edge/install.sh` 构建并安装，开机自动运行。
首次运行需要在 Mac 的“隐私与安全性”中允许它的“辅助功能”和“输入监控”。
安装脚本在本机生成一个固定的自签名证书，以后更新不用重新授权。

配对时在 FucairEdge 菜单选择“与电脑配对”，Mac 和电脑会显示同一个 6 位配对码，
一致就在两边都确认，之后自动连接。电脑在局域网中以 `_fucair-edge._tcp` 广播，
使用 TCP 7021 端口。“键鼠跨屏”页面可以开关整个功能，逐台设置已配对的 Mac
是否可以控制、是否共享剪贴板，或者移除它。

控制电脑时，Mac 的 Command、Option、Control 默认分别对应电脑的 Ctrl、Alt、
Win 键，左右键分开对应，例如右 Option 就是右 Alt；可在页面里改。快捷键映射把
Mac 习惯转成 Windows 操作，例如 Command-Tab 切换窗口、Command-Q 关闭程序、
Command/Option 加方向键跳行首行尾或按词移动，可以增删和恢复默认。
音量和播放键也会发到电脑。控制电脑期间，Mac 输入法产生的文字（例如 Mac 上的
语音输入）会输入到电脑，不会落到 Mac 的程序里；不需要时可在 FucairEdge 菜单关闭。
在 Mac 上按 Control-Option-Command-Esc 可随时收回指针。Mac 向这台电脑镜像
屏幕时键鼠跨屏自动暂停。

剪贴板共享在 Mac 连接期间双向同步文字和图片，密码管理器标记为私密的内容
不会同步。电脑锁屏或弹出管理员确认（UAC）时，Windows 不接受程序注入的输入，
指针会留在 Mac；以管理员身份运行的窗口也无法用 Mac 的键鼠操作。

默认录制目录是当前用户的
“视频\Fucairserver”。关闭或最小化窗口后接收仍在托盘运行；托盘菜单可恢复或退出。

下载更新后直接运行新安装包。设备名称、窗口设置和配对身份保存在
`%APPDATA%\Fucairserver`，升级和卸载默认保留，录制的视频也会保留。
在 Windows“设置 → 应用 → 已安装的应用”中卸载 Fucairserver。
安装器只移除本产品文件、快捷方式及所属网络规则。

如果设备可见但无法连接，检查网络是否是你信任的专用网络，必要时使用应用里的
Allow local network 按钮。组织策略控制的设备需要管理员调整策略。
网络隔离、访客 Wi-Fi、VPN 路由和发送端的音频输出选择也可能影响连接。

接收器只向局域网广播本机的 IPv4 地址，发送端不会再经运营商下发的 IPv6
前缀连接；该前缀会定期更换，长时间投屏会因此中断。电脑换到其他网络或获得
新的 IPv4 地址后，约 10 秒内自动重新广播。如果投屏中途仍会断开，先看
Windows 事件查看器中 WLAN-AutoConfig 是否记录了“网络被驱动程序断开连接”；
这类断线来自无线网卡驱动或电源管理，可更新网卡驱动，并在电源计划中把
“无线适配器设置 → 节能模式”的电池选项设为“最高性能”。
需要排查时，先从托盘退出，再在 PowerShell 中以 `Fucairserver.exe --log 2> 日志路径` 启动，
日志只写入你指定的文件。

本项目使用开源 AirPlay 接收实现，不隶属于 AirServer 或 Apple。
公开版本暂时使用 Windows 默认应用图标，本机私人图标不随公开包发布。
Miracast 组件仍为实验功能；Google Cast 和多发送端并排显示尚未完成。
不要把这些功能作为已支持功能承诺。

预览版本可能尚未获得发行者的代码签名。请仅从本仓库下载，并核对发布页的
SHA-256；数字签名和下载哈希是不同的验证手段。不要关闭 Windows 安全防护。
